Update break something? You can roll back with `bootc rollback`
Updates install automatically in the background. `ujust update` updates right away
Use `brew search` and `brew install` to install command line tools. They update automatically too
Use `Ctrl`-`Alt`-`T` to quickly open a terminal
`ujust --choose` will show you each shortcut and the script it's running
`ujust -n recipe_name` lets you preview a specific just recipe
`ujust changelogs` shows a summary of the package changes since the last update
`ujust install-davinci-resolve` sets up DaVinci Resolve with GPU acceleration
`ujust install-claude-desktop` installs Claude Desktop
Want your own prompt? `cp /usr/share/silverlit/starship.toml ~/.config/starship.toml` and edit away
Save your installed Homebrew packages and Flatpaks with `brew bundle dump`
A Flatpak application broke? Use Warehouse to downgrade to a working version
